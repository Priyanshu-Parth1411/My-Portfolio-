# Wireless Channel Estimation — source snapshot

This folder contains the supplied Python scripts, trained Keras model (`Final_Model.h5`), comparison result array and plots for the ConvLSTM2D Massive MIMO channel-estimation experiment. The original raw/training/test datasets are referenced by Google Drive links in `3 file drive link.txt` and are not duplicated here because of their size.

Note: scripts contain differing evaluation arrays and a simplified LS baseline. Validate the experimental methodology and regenerate consistent plots before presenting numerical improvements as final benchmark results.
