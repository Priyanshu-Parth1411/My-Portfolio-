# Priyanshu Parth — Engineering Portfolio

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required. The site uses local HTML, CSS, JavaScript and assets. Google Fonts are loaded online; system fallbacks are provided.

## Project media mapping
- SPIDER: `assets/SPIDER-Demo-Video.mp4` and `assets/SPIDER-Project-Poster.pdf`
- SARA: project photographs and dashboard/servo-angle screenshots in `assets/sara-*` (the SPIDER demo video is deliberately not assigned to SARA).
- IoT Smart Classroom: Raspberry Pi/ThingSpeak evidence images retained in the portfolio assets.
- Wireless Channel Estimation: source scripts, trained model and plots are described in the project details.
