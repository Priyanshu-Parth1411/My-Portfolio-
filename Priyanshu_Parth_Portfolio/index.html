A four-legged quadruped built around an ESP32 controller, eight MG90S micro servos and a browser-based dashboard hosted directly by the ESP32. The interface supports directional motion commands, stand/sleep poses, per-servo angle tuning and coordinated gait parameters.

Deep Learning-Based Wireless Channel Estimation

A deep-learning study of channel estimation for 128×128 Massive MIMO. The supplied implementation generates time-varying Rayleigh channel samples, trains a ConvLSTM2D model and evaluates NMSE against a simulated Least Squares baseline across SNR values.
